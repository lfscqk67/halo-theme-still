# Changelog

All notable changes to Still for Halo will be documented in this file.

## [1.0.0] - 2026-09-19

### Added
- Minimal responsive homepage and article layout.
- Optional site avatar.
- Dark mode toggle.
- Article cover support.
- Markdown table styling.
- Dark code blocks with common highlight.js / Prism token colors.
- Archive, category, tag, author, page, and post templates.
- Halo comment extension support.
- Chinese and English UI strings.

### Changed
- Public release contains no personal avatar, demo cover, site title, or personal preset content.
